1מתחילים לעבוד עם ESP32

כדי שתוכנת Arduino IDE תכיר את ה־ESP32, התקנו את חבילת הלוחות שלו דרך Boards Manager. ההורדה וההתקנה הראשונית עשויות להימשך זמן, משום שהחבילה כוללת כלי תכנות וקבצים רבים.

בחירת הלוח

בחרנו בתפריט הלוחות את ESP32 Dev Module. הבחירה אומרת לתוכנה לאיזה בקר אנחנו עומדים להעלות את הקוד.

בחירת החיבור

בחרנו את יציאת ה־USB המתאימה והעלינו תוכנית בסיסית. כך בדקנו שהמחשב, הכבל והלוח מתקשרים.

טיפ: התקנת חבילת ה־ESP32 נעשית פעם אחת בכל מחשב. לאחר ההתקנה, העלאת תוכניות חדשות מהירה בהרבה.

2מהו מנוע סרוו?

סרוו הוא מנגנון שיודע להגיע לזווית שנבקש ולשמור עליה. בסרוו קטן טיפוסי ניתן בדרך כלל לנוע בקירוב בין 0° ל־180°, אך הטווח המדויק תלוי בדגם.

התקשורת מזכירה PWM, אך כאן משמעות רוחב הפולס היא הזווית הרצויה. בסרוו נפוץ נשלח פולס בערך כל 20 אלפיות השנייה.

חיבור בטוח: חוט האות מתחבר לפין מתאים ב־ESP32, אך את מתח הסרוו מומלץ לספק ממקור 5V מתאים — במיוחד תחת עומס. חובה לחבר GND משותף בין ספק הכוח ל־ESP32. אין לחבר את מתח הסרוו לפין 3.3V.

דוגמה: תנועה מ־0° עד 180° וחזרה

#include <ESP32Servo.h>

Servo lidServo;
const int servoPin = 13;

void setup() {
  lidServo.attach(servoPin);
}

void loop() {
  for (int angle = 0; angle <= 180; angle++) {
    lidServo.write(angle);
    delay(15);
  }

  for (int angle = 180; angle >= 0; angle--) {
    lidServo.write(angle);
    delay(15);
  }
}
שימו לב: מספר הפין בדוגמה הוא הצעה בלבד. יש להתאים אותו לחיבור האמיתי בלוח שלכם ולהימנע מפינים שמיועדים לרכיבים אחרים.

3הפרויקט: פח חכם

תכננו מנגנון שמרים את מכסה הפח בכ־90°. קיבענו את מנוע הסרוו לפח בעזרת דבק חם וחיברנו לציר מקל/זרוע מ־RTPLA. הזרוע מתרגמת את סיבוב הסרוו להרמת המכסה.

מצב סגור

הסרוו נמצא בזווית ההתחלתית והמכסה מונח על הפח.

מצב פתוח

הסרוו נע לזווית שנבחרה — בערך 90° — והזרוע מרימה את המכסה.

#include <ESP32Servo.h>

Servo lidServo;
const int servoPin = 13;

void setup() {
  lidServo.attach(servoPin);
}

void loop() {
  lidServo.write(90);  // פתיחת המכסה
  delay(2000);
  lidServo.write(0);   // סגירת המכסה
  delay(2000);
}
השלב הנוכחי: עדיין אין חיישן. התוכנית מפעילה את הפח אוטומטית לפי זמן קבוע. בהמשך נוסיף חיישן שיזהה יד או אדם ורק אז יפתח את המכסה.

4משימות לשיעורי הבית

חובה

משימה 1 — בדיקת ESP32

פתחו תוכנית חדשה, בחרו ESP32 Dev Module והעלו תוכנית בסיסית. כתבו לעצמכם איזה Port עבד.

חובה

משימה 2 — שלוש זוויות

הזיזו את הסרוו ל־0°, לאחר מכן ל־45°, לאחר מכן ל־90°, ובסוף חזרה ל־0°. כל מצב יישאר למשך שנייה.

חובה

משימה 3 — לולאת תנועה

כתבו לולאת for שמזיזה את הסרוו בהדרגה מ־0° עד 90°. לאחר מכן כתבו לולאה שמחזירה אותו.

חובה

משימה 4 — כוונון המכסה

מצאו את הזווית הנכונה לפתיחה מלאה בלי שהסרוו דוחף את המכסה מעבר לגבול המכני. תעדו את זווית הסגירה וזווית הפתיחה.

אתגר למתקדמים

פתיחה רכה וסגירה איטית

במקום לקפוץ מיד בין 0° ל־90°, הזיזו את המכסה בהדרגה. פתחו אותו מהר יחסית, המתינו שתי שניות וסגרו אותו לאט יותר. רמז: השתמשו בשתי לולאות ובערכי delay() שונים.
