ג'ויסטיק אנלוגי

מודול ג'ויסטיק כולל למעשה שני פוטנציומטרים - אחד לכל ציר (X ו-Y) - ולחצן דיגיטלי שמופעל בלחיצה על הידית עצמה. זהו רכיב קלט נהדר לשליטה ברובוט, במשחק, או בכל פרויקט שדורש כיוון ועוצמה.

מפרט

  • פינים: VRx, VRy (אנלוגי), SW (דיגיטלי, לחצן), VCC, GND
  • פלט צירים: ערך אנלוגי 0-1023, מרכז בסביבות 512
  • שימושים נפוצים: שליטה ברובוט, בקר משחק, תפריט ניווט

חיבור

VCC ל-5V, GND ל-GND, VRx ו-VRy לשתי כניסות אנלוגיות (למשל A0, A1), SW לפין דיגיטלי (למשל פין 2).

קוד לדוגמה

const int xPin = A0;
const int yPin = A1;
const int swPin = 2;

void setup() {
  Serial.begin(9600);
  pinMode(swPin, INPUT_PULLUP);
}

void loop() {
  int x = analogRead(xPin);
  int y = analogRead(yPin);
  bool pressed = digitalRead(swPin) == LOW;

  Serial.print("X: "); Serial.print(x);
  Serial.print(" Y: "); Serial.print(y);
  Serial.print(" Button: "); Serial.println(pressed);
  delay(200);
}

רעיון לתרגול

לתרגם את ערכי ה-X וה-Y לכיוון תנועה (קדימה/אחורה/ימינה/שמאלה) ולשלוט בכך ברובוט על שני מנועים.
