3תזכורת: המכונית משיעור 2Recap: the car from Lesson 2

בנינו מכונית עם 4 מנועים, מגשר L298N שנותן להם כוח, וחיישן HC-SR04 מלפנים. הקוד השתמש ב-if / else: אם קרוב — לעצור, אחרת — לנסוע. We built a car with 4 motors, an L298N H-bridge to power them, and an HC-SR04 sensor up front. The code used if / else: if close — stop, else — drive.

  • L298N — פין חלש של הארדואינו לא מפעיל מנוע; המגשר לוקח כוח מסוללה ומאפשר גם כיווןL298N — a weak Arduino pin can't run a motor; the H-bridge takes battery power and also sets direction
  • שתי פונקציות בלבד: forward() ו-stopCar()Only two functions: forward() and stopCar()
אבל — המכונית רק עצרה מול מכשול. זו עדיין לא "נהיגה עצמית".But — the car only stopped at an obstacle. That's not really "self-driving" yet.

חיווט המכונית (כמו בשיעור 2)The car's wiring (as in Lesson 2)

4 מנועים, מגשר אחד: שני המנועים בכל צד מחוברים יחד לאותו ערוץ ב-L298N. לכן בקוד יש רק שני צדדים — שמאל וימין.4 motors, one H-bridge: the two motors on each side are wired together into the same L298N channel. So in code there are only two sides — left and right.

⚠️ הסוללה של המנועים והארדואינו חייבים גראונד משותף.⚠️ The motor battery and the Arduino must share a common ground.

4רגע — למה שני פיני IN לכל צד?Wait — why two IN pins per side?

פין דיגיטלי יודע רק שני מצבים: דלוק / כבוי. הוא יכול להדליק מנוע — אבל לא להפוך אותו. כדי לנסוע אחורה צריך להחליף את הקוטביות (+/–) של המנוע. A digital pin has only two states: on / off. It can turn a motor on — but it can't reverse it. To go backward you must swap the motor's polarity (+/–).

בדיוק לזה נועד המגשר H (H-bridge): לכל ערוץ יש זוג פינים (IN1+IN2) שקובעים לאן זורם הזרם — כלומר את הכיוון. פין EN נפרד שולט במהירות (PWM). That's exactly what an H-bridge is for: each channel has a pair of pins (IN1+IN2) that set which way the current flows — i.e. the direction. A separate EN pin sets the speed (PWM).

IN1IN2תוצאהResult
10קדימהForward
01אחורהReverse
00עצירה (חופשי)Stop (coast)
11בלימהBrake
לכן: 4 מנועים, 2 צדדים, 2 ערוצים — אבל 4 פיני IN (זוג לכל צד לכיוון) + 2 פיני EN (למהירות).So: 4 motors, 2 sides, 2 channels — but 4 IN pins (a pair per side for direction) + 2 EN pins (for speed).

5שלב 0: מכונית שמתחמקת (לא רק עוצרת)Level 0: a car that avoids (not just stops)

מכונית שנוהגת לבד צריכה לצאת מהצרה: אם חסום — לסגת קצת, להסתובב, ולהמשיך. בשביל זה צריך שני כיוונים חדשים. A self-driving car must get out of trouble: if blocked — back up a bit, turn, and carry on. For that we need new directions.

ארבע תנועות מה-L298NFour moves from the L298N

  • קדימה: שני הצדדים קדימהForward: both sides forward
  • אחורה: שני הצדדים אחורה (הופכים IN1/IN2)Backward: both sides reverse (flip IN1/IN2)
  • פנייה ימינה: שמאל קדימה, ימין אחורה ← מסתובב במקוםTurn right: left forward, right back → spins in place
  • פנייה שמאלה: הפוךTurn left: the opposite
הטריק: כיוון מנוע נקבע ע"י מי מה-IN גבוה. הופכים אותם — והגלגל מסתובב הפוך.The trick: motor direction is set by which IN pin is HIGH. Flip them — the wheel spins the other way.

אחורה = להפוך את IN1/IN2Backward = flip IN1/IN2

void forward() {
  digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW);
  digitalWrite(IN3, HIGH); digitalWrite(IN4, LOW);
}
void backward() {
  digitalWrite(IN1, LOW);  digitalWrite(IN2, HIGH);
  digitalWrite(IN3, LOW);  digitalWrite(IN4, HIGH);
}
void turnRight() {      // left fwd, right back
  digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW);  digitalWrite(IN4, HIGH);
}

אותה מהירות ל-ENA/ENB בכל תנועה.Same speed on ENA/ENB for every move.

6שלב 0: ההחלטה של המכוניתLevel 0: the car's decision

אותו if / else משיעור 2 — אבל בענף ה"חסום" יש עכשיו רצף קטן של פעולות במקום סתם עצירה. The same if / else from Lesson 2 — but the "blocked" branch now runs a small sequence instead of just stopping.

if (distanceCm <= 15) {   // blocked
  stopCar();   delay(200);
  backward();  delay(400);
  turnRight(); delay(400);
} else {
  forward();               // clear -> drive
}

7לוקחים את ההגה 🕹️Take the wheel 🕹️

שימו לב לדבר הכי חשוב היום: פונקציות התנועה נשארות בדיוק אותו דבר. מה שמשתנה זה רק מי מחליט איזו פונקציה להפעיל. Notice the most important thing today: the motion functions stay exactly the same. All that changes is who decides which function to call.

// self-driving: the SENSOR decides
if (distance <= 15) turnRight();
else                forward();

// remote: YOU decide (a button)
if (button == UP)    forward();
else if (button == RIGHT) turnRight();

אותו "גוף", מוח אחר. זה מה שהופך רובוט לגמיש.Same "body", different brain. That's what makes a robot flexible.

8שלב 1: שלט IR — איך זה עובדLevel 1: IR remote — how it works

בדיוק כמו שלט הטלוויזיה: השלט מהבהב אור אינפרא-אדום שאנחנו לא רואים. כל כפתור שולח קוד מספרי אחר. המקלט על המכונית מפענח את הקוד. Just like your TV remote: it flashes infrared light we can't see. Each button sends a different numeric code. The receiver on the car decodes it.

  • 🔦 קו ראייה חובה — האור לא עובר דרך קיר או יד🔦 Line of sight required — the light won't pass a wall or hand
  • ⬅️ חד-כיווני — השלט מדבר, המכונית רק מקשיבה➡️ One-way — the remote talks, the car only listens
  • ✅ פשוט וזול — השלט כבר מוכן✅ Simple and cheap — the remote is ready-made

9שלב 1: קודם — ללמוד את קודי השלטLevel 1: first — learn the remote's codes

כל שלט שולח מספרים אחרים, אז קודם קוראים אותם פעם אחת ורושמים. מעלים את הסקצ' הקצר, פותחים Serial Monitor, ולוחצים על כל כפתור. Every remote sends different numbers, so first we read them once and write them down. Upload the short sketch, open the Serial Monitor, and press each button.

הרכיבThe part

  • מודול מקלט IR (VS1838 / HX-M121) + השלט הקטןIR receiver module (VS1838 / HX-M121) + the small remote
  • ספרייה: IRremote (בתפריט Manage Libraries, לחפש)Library: IRremote (Manage Libraries → search)
חיווט המקלט: OUT→D8, VCC→5V, GND→GND. שלושה חוטים בלבד.Receiver wiring: OUT→D8, VCC→5V, GND→GND. Just three wires.

קוראים את הקודיםRead the codes

#include <IRremote.h>
const int IR_RECEIVE_PIN = 8;

void setup() {
  Serial.begin(9600);
  IrReceiver.begin(IR_RECEIVE_PIN);
}
void loop() {
  if (IrReceiver.decode()) {
    Serial.println(IrReceiver.decodedIRData.command, HEX);
    IrReceiver.resume();
  }
}

10שלב 1: המכונית נוהגת בשלט IRLevel 1: the car drives by IR remote

ממלאים את חמשת הקודים שרשמנו, וכל כפתור מפעיל אחת מפונקציות התנועה שכבר יש לנו. Fill in the five codes we wrote down, and each button calls one of the motion functions we already have.

if (IrReceiver.decode()) {
  uint8_t cmd = IrReceiver.decodedIRData.command;
  if      (cmd == BTN_UP)    forward();
  else if (cmd == BTN_DOWN)  backward();
  else if (cmd == BTN_LEFT)  turnLeft();
  else if (cmd == BTN_RIGHT) turnRight();
  else if (cmd == BTN_OK)    stopCar();
  lastCmd = millis();
  IrReceiver.resume();
}
// no button for a moment -> stop, so it won't run away
if (millis() - lastCmd > 200) stopCar();

11שלב 2: RF433 — רדיו במקום אורLevel 2: RF433 — radio instead of light

RF משתמש בגלי רדיו בתדר 433MHz. בניגוד ל-IR, רדיו לא צריך קו ראייה — הוא עובר דרך קירות ומגיע רחוק הרבה יותר. RF uses radio waves at 433MHz. Unlike IR, radio needs no line of sight — it passes through walls and reaches much farther.

לחצו "שלח" עם ובלי קיר — ותראו את ההבדל:Press "send" with and without a wall — and see the difference:

חיסרון: אין קו ראייה = אין "לכוון" — הרדיו מגיע לכל הכיוונים. וגם: שני רדיואים באותו תדר יכולים להפריע זה לזה.Downside: no line of sight = no "aiming" — radio goes everywhere. Also: two radios on the same frequency can interfere.

12שלב 2: הפעם בונים גם את השלטLevel 2: this time we build the remote too

ב-IR השלט היה מוכן. ב-RF יש לנו זוג מודולים — משדר (TX) ומקלט (RX) — אז המשדר הוא ארדואינו שני עם כפתורים, והמקלט על המכונית. With IR the remote came ready. With RF we get a pair of modules — a transmitter (TX) and a receiver (RX) — so the remote is a second Arduino with buttons, and the receiver is on the car.

  • ספרייה: rc-switch — שולחים ומקבלים מספרים פשוטיםLibrary: rc-switch — send and receive simple numbers
  • מסכימים על קוד לכל כיוון (11=קדימה, 12=אחורה...)Agree on a code per direction (11=fwd, 12=back...)
  • אנטנה: חוט ~17 ס"מ משפר מאוד את הטווחAntenna: a ~17 cm wire greatly improves range
⚠️ שינוי חיווט אחד: ה-RX חייב פין פסיקה (D2 או D3). זה בדיוק ה-IN1 שלנו! אז מזיזים את IN1 מ-D2 ל-D8, וה-RX יושב על D2. ⚠️ One wiring change: the RX needs an interrupt pin (D2 or D3). That's exactly our IN1! So we move IN1 from D2 to D8, and the RX sits on D2.

המשדר (השלט)The transmitter (remote)

long code = CODE_STOP;
if (digitalRead(BTN_UP)==LOW)   code=CODE_UP;
else if(digitalRead(BTN_LEFT)==LOW) code=CODE_LEFT;
// ...
mySwitch.send(code, 24);   // over the air

המקלט (המכונית)The receiver (car)

if (mySwitch.available()) {
  long code = mySwitch.getReceivedValue();
  if (code==CODE_UP) forward();
  // ... map codes to moves
  mySwitch.resetAvailable();
}

13פינאלה: נהיגה מהטלפון 📱Finale: drive from your phone 📱

הפעם אין שלט נפרד בכלל — הטלפון הוא השלט. מודול HC-05/HC-06 על המכונית מדבר עם אפליקציית Dabble החינמית, שיש בה ג'ויסטיק על המסך. This time there's no separate remote at all — your phone is the remote. An HC-05/HC-06 module on the car talks to the free Dabble app, which has an on-screen gamepad.

  • Bluetooth הוא דו-כיווני — אפשר גם לשלוח נתונים חזרה לטלפון (למשל מרחק)Bluetooth is two-way — you can also send data back to the phone (e.g. distance)
  • בלי לכתוב קוד בצד הטלפון — Dabble עושה את זהNo phone-side coding — Dabble handles it
⚠️ המודול על פיני TX/RX (D1/D0) — אלה גם פיני ההעלאה. נתקו את חוטי המודול לפני Upload וחברו אחרי. (או SoftwareSerial על פינים פנויים.) ⚠️ The module is on TX/RX (D1/D0) — those are the upload pins too. Unplug the module's wires before Upload and reconnect after. (Or use SoftwareSerial on free pins.)

הקוד — שוב אותן פונקציותThe code — the same functions again

#define CUSTOM_SETTINGS
#define INCLUDE_GAMEPAD_MODULE
#include <Dabble.h>

void loop() {
  Dabble.processInput();       // read the phone
  if      (GamePad.isUpPressed())    forward();
  else if (GamePad.isDownPressed())  backward();
  else if (GamePad.isLeftPressed())  turnLeft();
  else if (GamePad.isRightPressed()) turnRight();
  else                             stopCar();
}

הרעיון האחד להיוםThe one idea for today

מכונית אחת, כמה "מוחות": חיישן, IR, RF, טלפון. פונקציות התנועה תמיד אותן — מפרידים בין "מה לעשות" ל"איך הפקודה מגיעה". One car, several "brains": sensor, IR, RF, phone. The motion functions are always the same — separate "what to do" from "how the command arrives".

איזו טכנולוגיה מתי?Which technology when?

  • IR — קרוב, בקו ישר, זול (צעצועים, טלוויזיה)IR — close, straight line, cheap (toys, TV)
  • RF — רחוק, דרך קירות, בלי לכוון (שער חשמלי, אזעקה)RF — far, through walls, no aiming (gates, alarms)
  • Bluetooth — מהטלפון, דו-כיווני (מכונית חכמה)Bluetooth — from a phone, two-way (smart car)
