5איך סונאר מודד מרחקHow sonar measures distance

החיישן צועק צליל על-קולי (אנחנו לא שומעים אותו), הצליל פוגע בעצם וחוזר כהד. החיישן מודד כמה זמן לקח לצליל לצאת ולחזור. The sensor shouts an ultrasonic sound (we can't hear it), it hits an object and echoes back. The sensor measures the time for the sound to go and return.

מהירות הקול ≈ 343 מטר לשנייה = 0.0343 ס״מ בכל מיקרו-שנייה (µs). Speed of sound ≈ 343 m/s = 0.0343 cm per microsecond (µs).

הנוסחהThe formula

distance = (time × 0.0343) / 2

למה חלקי 2? כי הזמן שמדדנו הוא לשם ובחזרה — הלוך ושוב. Why divide by 2? Because the time measured is for the trip there AND back.

זמןtime: — µs · — cm

6החיישן מקרוב — Trig ו-EchoThe sensor up close — Trig & Echo

לחיישן הסונאר יש 4 פינים. שניים לחשמל, ושניים ל"שיחה" עם הארדואינו: The sonar has 4 pins. Two for power, two to "talk" with the Arduino:

  • VCC → 5V  ·  GND → GND (חשמלpower)
  • Trig → אנחנו שולחים פולס קצר של 10µs = "עכשיו תמדוד!"we send a short 10µs pulse = "measure now!"
  • Echo → החיישן מחזיר פין שנשאר גבוה בדיוק כמשך הזמן של ההד. אנחנו מודדים אותו עם pulseIn().the sensor holds this pin HIGH for exactly the echo time. We measure it with pulseIn().
שימו לב: Trig הוא פולס חד-פעמי להתחלה — הוא לא חוט שעון. את חוט השעון נפגוש בתצוגה (השקף הבא). Note: Trig is a one-shot start pulse — it is not a clock wire. We'll meet the clock wire in the display (next slide).

רצף המדידהThe measurement sequence

// 1) fire the trigger
digitalWrite(trig, HIGH);
delayMicroseconds(10);
digitalWrite(trig, LOW);

// 2) time the echo (round trip, µs)
long t = pulseIn(echo, HIGH);

// 3) time -> distance
float cm = t * 0.0343 / 2;

7התצוגה — ולמה יש "חוט שעון"?The display — and why a "clock wire"?

תצוגת הספרות מקבלת מידע בשני חוטים:The digit display receives data on two wires:

  • DIO — נתונים: הביטים עצמם (0 או 1)data: the bits themselves (0 or 1)
  • CLK — שעון: פעימה שאומרת "עכשיו! קרא ביט"clock: a beat that says "now! read a bit"

בלי שעון משותף, הצד המקבל לא יודע מתי כל ביט תקף. השעון הוא המטרונום ששני הצדדים סופרים לפיו — זו "תקשורת טורית". Without a shared clock, the receiver wouldn't know when each bit is valid. The clock is the metronome both sides count to — this is "serial communication".

בכל עלייה של השעון, התצוגה "צובטת" את הערך שנמצא כרגע על חוט הנתונים. On every rising edge of the clock, the display "latches" whatever value is on the data wire.

9שלב 1 — סונאר למסךLevel 1 — sonar to the screen

המטרה: מספר מרחק מתעדכן בחלון המוניטור הטורי.Goal: a live distance number in the Serial Monitor.

const int trigPin = 9;
const int echoPin = 10;

void setup() {
  Serial.begin(9600);
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
}

void loop() {
  digitalWrite(trigPin, LOW);  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH); delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  long duration = pulseIn(echoPin, HIGH);
  float distanceCm = duration * 0.0343 / 2;

  Serial.print("Distance: ");
  Serial.print(distanceCm);
  Serial.println(" cm");
  delay(200);
}

10שלב 2 — מוסיפים תצוגהLevel 2 — add the display

מעבירים את הקריאה לפונקציה משלנו, ומדפיסים על התצוגה. צריך את הספרייה TM1637Display. Move the reading into our own function, and print on the display. Needs the TM1637Display library.

#include <TM1637Display.h>
const int trigPin=9, echoPin=10, CLK=4, DIO=5;
TM1637Display display(CLK, DIO);

void setup() {
  Serial.begin(9600);
  pinMode(trigPin, OUTPUT); pinMode(echoPin, INPUT);
  display.setBrightness(5);
}

void loop() {
  int distanceCm = getDistanceCm();     // our function
  Serial.println(distanceCm);
  display.showNumberDec(distanceCm);      // show on display
  delay(200);
}

int getDistanceCm() {
  digitalWrite(trigPin, LOW);  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH); delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
  long duration = pulseIn(echoPin, HIGH);
  return duration * 0.0343 / 2;
}

11שלב 3 — נורית אזהרה חכמהLevel 3 — a smart warning LED

כאן נכנס ה-if / else וגם map(): הופכים "מרחק" ל"קצב הבהוב". Here the if / else and map() come in: turn "distance" into "blink speed".

const int START_CM = 30;

if (distanceCm > START_CM) {
  digitalWrite(ledPin, LOW);   // far: off
  delay(200);
} else {
  int d = map(distanceCm, 0, START_CM, 40, 500);
  digitalWrite(ledPin, HIGH); delay(d);
  digitalWrite(ledPin, LOW);  delay(d);
}

map: מרחק 0 → 40ms (מהיר) · מרחק 30 → 500ms (איטי) map: distance 0 → 40ms (fast) · distance 30 → 500ms (slow)
